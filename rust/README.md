# Стенд на Rust

Команды выполняются из каталога `rust/`. Эталон – Node 26.3.1, V8 14.6.202.34-node.20, arm64 macOS, сборка Homebrew. Для сборки нужен Rust edition 2024 и компилятор C++20. Node нужен для сравнений с TypeScript.

## Числа

`node tools/check-math.mjs` собирает проверяющую программу и передаёт ей входы и ожидаемые binary64 непосредственно из Node. Для каждой операции берутся 100 000 значений на рабочих диапазонах, ещё 100 000 на смешанных диапазонах и декартово произведение граничных значений. Сравнение – по всем 64 битам, включая знак нуля и биты NaN. Векторы не записываются в репозиторий.

| Операция | Реализация |
| :-- | :-- |
| sin, cos | В установленной libnode экспортированы `v8::base::ieee754::sin/cos`. Флага `--use-libm-trig-functions` у этой сборки нет. Используются ядра fdlibm, включая редукцию больших аргументов по π/2. |
| exp, log, log1p, tanh, atan2 | Функции из того же исходника V8, включая внутренние expm1 и atan, особый случай exp(1) и signaling NaN при выходе логарифма за область определения. |
| hypot | Алгоритм math.tq: максимум модулей, нормирование, умножение на масштаб после sqrt. Для трёх и более аргументов учитывается компенсация потери точности. Бесконечность имеет приоритет над NaN. |
| abs, sqrt, ceil, floor | Операции binary64, как у Float64Abs, Float64Sqrt, Float64Ceil и Float64Floor. Константы PI и SQRT2 имеют ближайшее представимое значение. |
| round, sign, min, max | Ветви ECMAScript: половины округляются к большему, знак нуля сохраняется, NaN распространяется. |
| ToInt32, ToUint32, imul | Выделение младших 32 бит усечённой мантиссы и умножение по модулю 2³². hashUnit и hueNoise повторяют math.ts, с беззнаковыми сдвигами. |

Исходники эталона: [ieee754.cc](https://github.com/nodejs/node/blob/v26.3.1/deps/v8/src/base/ieee754.cc), [выбор функций](https://github.com/nodejs/node/blob/v26.3.1/deps/v8/src/codegen/external-reference.cc), [math.tq](https://github.com/nodejs/node/blob/v26.3.1/deps/v8/src/builtins/math.tq). Выбранные ядра собраны статически в jscompat, лицензии лежат рядом с Cargo.toml крейта. Исходные скобки и промежуточные присваивания сохранены. В дизассемблере установленной libnode внутри полинома sin видна серия инструкций fmadd. Например, при −0,6962983277626336 отдельное округление умножения и сложения меняет последний бит. Поэтому только для этих ядер используется режим Clang `-ffp-contract=on` без fast-math. В формулах модели обычные операции Rust округляются отдельно. Другая архитектура или компилятор требуют повторной битовой сверки.
