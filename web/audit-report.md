# Проверка лаборатории активного восприятия

**Результат смешанный.** На 20 конфигурациях полный контур удержал A после выхода из-за стены в 16 случаях и различил пару в 17. Первый порядок справился с этими задачами в 11 и 0 случаях соответственно. Ошибка прогноза окна при повторе выросла примерно на 0,058. Для обнаружения повтора по принятому критерию нужен прирост больше 0,08.

## Бенчмарк до и после

В каждой ячейке слева приведён исходный результат, справа – результат после исправлений. Прочерк означает, что показатель в этом условии не измерялся. Для первого порядка исходного измерения не было.

Исходный прогон использовал зёрна 1–7 при одной геометрии на сценарий, вердикт был `supported`. Итоговый прогон использует зёрна 1–20 с разными позициями и скоростями, вердикт – `mixed`. Ошибки в двух версиях измеряются по разным протоколам. Для воспроизведения исходной таблицы служит коммит `9bb6566`. В обеих версиях команда из каталога `web/` – `npm run bench`.

Оценщик проверяет исходный номер трека A на следующем шаге после выхода из-за стены. Для успеха в «Конфликте» A и B должны иметь разные ближайшие треки в радиусе 12 единиц не менее шести шагов подряд. Доли посчитаны по эпизодам. Для вердикта полный контур должен опередить каждый из трёх контролей (первый порядок, только запись, лишняя память) более чем на 20 п. п. хотя бы по одной из этих задач. Ошибка действия – доля несовпавших клеток, усреднённая по шагам 17–40, затем по конфигурациям. Живой режим и повтор сравниваются на одинаковых шагах.

## Границы вывода

Обнаружение повтора на этих конфигурациях подтвердить не удалось. Агент предсказывает поверхности по движению и приблизительной площади треков, а стену – по уже наблюдавшимся участкам. Доля несовпадений учитывает и клетки фона. Положительный прирост ошибки сам по себе не достигает порога протокола.

Изменение весов и ёмкости причинно меняет решения в проверочных сценах. Поиск ограничен бюджетом и набором локальных изменений. В контроле с памятью уравнено число слотов, точное равенство затрат процессора и памяти в байтах не измерялось.

В этой версии правила заданы вручную. Оценка освещения сохраняется, обучение сенсомоторике (P8) отсутствует. Самомодель прогнозирует исход одного исполненного решения. Обучение на её ошибках, сравнение кандидатов взгляда, протокол внимания (P10) и Genesis-тест остаются за рамками опыта. Поле `prediction` обозначает качество сопоставления. Феноменальное сознание не установлено.
