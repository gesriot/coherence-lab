# coherence-lab

Исследовательский стенд по модели сознания Йоши Баха. Агент собирает перцептивную сцену из конкурирующих гипотез, воспринимает состояние собственного восприятия и использует это для управления вниманием. Стенд проверяет функциональные предпосылки сознания и их причинную роль; наличие феноменального опыта он не устанавливает.

Интерактивная лаборатория: https://gesriot.github.io/coherence-lab/

- `docs/spec.md` – техническое задание и сводка модели, сверенная с первоисточниками.
- `docs/results.md` – результаты экспериментов, включая недействительные прогоны и их причины.
- `docs/version-b.md` – проект и результаты версии B: самоорганизующийся субстрат.
- `web/` – реализация на TypeScript: интерактивная лаборатория «Дирижёр», бенчмарк абляций и Genesis-тест.
- `rust/` – перенос на Rust с побайтной сверкой выводов с TypeScript. Сейчас перенесена версия A до команды `bench`. Команды и проверки – в `rust/README.md`.

## Запуск `web/`

Нужен Node.js 22.18 или новее.

```sh
cd web
npm install
npm run dev        # дев-сервер Vite
npm run typecheck
npm test
npm run build
```

Эксперименты:

```sh
npm run bench                     # версия A без обучения
npm run genesis                   # Genesis-тест, этап 1
npm run sensorimotor:feasibility  # Genesis-тест, этап 2: контроли
npm run sensorimotor              # Genesis-тест, этап 2: сравнение
npm run substrate:b0              # версия B: прогноз движения
npm run substrate:b1b             # версия B: слежение за скрытым объектом
npm run substrate:b3b             # версия B: своё и чужое движение
```
